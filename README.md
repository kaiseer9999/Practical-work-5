# Практическая работа №5

## Тема

Бинарная классификация и подбор порога классификации.

## Цель работы

Обучить модель бинарной классификации, получить вероятности классов с помощью `predict_proba()`, построить ROC- и PR-кривые, вычислить AUC и подобрать порог классификации с учётом стоимости ошибок.

## Датасет

Используется датасет о заболеваниях сердца.

Целевая переменная:

`Heart Disease Status`

Значения целевой переменной:

* `No` — заболевание отсутствует;
* `Yes` — заболевание присутствует.

Для обучения:

* `No` преобразуется в `0`;
* `Yes` преобразуется в `1`.

## Модель

Для классификации используется логистическая регрессия (`LogisticRegression`).

Категориальные признаки преобразуются в числовой формат с помощью `OneHotEncoder`.

Пропущенные значения обрабатываются с помощью `SimpleImputer`.

Числовые признаки стандартизируются с помощью `StandardScaler`.

Данные разделяются на обучающую и тестовую выборки в соотношении 80/20.

## Основные этапы

1. Загрузка и анализ датасета.
2. Подготовка целевой переменной.
3. Обработка пропущенных значений.
4. Кодирование категориальных признаков.
5. Разделение данных на train и test.
6. Обучение логистической регрессии.
7. Получение вероятностей с помощью `predict_proba()`.
8. Построение ROC-кривой и расчёт ROC-AUC.
9. Построение PR-кривой и расчёт PR-AUC.
10. Оценка модели при стандартном пороге `0.5`.
11. Проверка различных порогов классификации.
12. Выбор оптимального порога с учётом стоимости FP и FN.
13. Сравнение результатов при пороге `0.5` и выбранном пороге.

## Вывод

Подбор порога позволяет учитывать различную стоимость ложноположительных (FP) и ложноотрицательных (FN) ошибок. Оптимальный порог выбирается не только по общей точности модели, но и с учётом того, какая ошибка является более существенной для поставленной задачи.
